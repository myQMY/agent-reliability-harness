# W3 `tool_retry` 护栏：单变量 A/B 的跨 seed 证据

> 由 `python -m eval.ab_sweep` 依据 `w3_tool_retry_sweep.jsonl` 如实生成；不含生成时间，同命令两次产物逐字节一致。
> 本模块不新增护栏、不改判分口径、不修改任何既有留档：四份 2×2 配置的 `run_id` / `config.json` / `result_rows.jsonl` / `report.md`、`w3_guard_matrix.md`、`w3_robustness.*` 与冻结基线全部一字节未动。

## 为什么要做这份检查

既有 [多种子稳健性检验](w3_robustness.md) 已经证明：2×2 全因子报告只在 `seed=11` 上跑过一次，10 条任务、k=3，`pass^k` 分辨率 0.10，而换 30 个 seed 后 `schema_validation` 在多数 seed 上完全测不到提升。**`seed=11` 是偏乐观样本**。因此本轮新增护栏不再只报一次 A/B：对照纪律是「同一 seed 集、只差 `[guards].enabled`、附符号分布」。

## 机制：这条护栏到底修了什么

`tool_retry` 是路线表里「退避」在本同步确定性 harness 里的落地形态：工具层报错后追加一条 `[GUARD-REJECT]` 消息要求重发，重试受共享的 `MAX_GUARD_REJECTIONS` 上限约束。**不做真实 sleep、不引入指数延迟**——那会破坏逐字节复现，也不是本实验的自变量。

四类人为缺陷与运行时机制的归属（互不重叠，便于单变量归因）：

| 缺陷 | 既有机制 | `tool_retry` |
| --- | --- | --- |
| `bad_json` | W1 的 JSON 重试（只提示，不恢复被跳过的动作） | 不触发：未进入 `tools.call` |
| `bad_args` | `schema_validation` 在执行前拦下 | 工具报错后重发 |
| `wrong_tool` | 两条执行前护栏都明确放行 | **唯一能覆盖它的护栏** |
| `duplicate_call` | `idempotency` 拦重复写 | 工具层不报错，不触发 |

- **只有可恢复的注入故障能被修好**。`SeededBackend` 注入故障时会把干净动作存进 `_pending_correct`，护栏的拒绝消息才能触发它重发；任务脚本里**固有的**缺陷（如 `T07` 的 `refund_money` 错工具、`T08` 的 `refund_order` 缺参数）没有这份干净动作，重发只是让后端推进到下一个脚本项。这些 trial 在 trace 里照样产生 `role=guard` 的 span，但任务仍然失败——护栏没有越界去修固有缺陷。
- **错误证据如实保留**：报错的 `tool` span 与 `errors` 都在原处，护栏只额外追加一个 `guard` span 与一条拒绝消息，因此 `invalid_calls` **不会因这条护栏而下降，只会持平或上升**：错误确实发生过一次，重发又会让后端多消耗一次输出，若后续动作本身也有缺陷就会再报一次错。本轮两组合计的变化见上表；中间指标下降、持平、上升都不能替代 `pass^k`。`grader` 不消费 `guard` span，判分口径不因开关改变。
- **正效应 seed 集合与既有两条护栏不是包含关系**：作用位置不同（执行前 vs 失败后），在不同随机流下各有独自生效的 seed。不能因为「多覆盖一类错误」就推断它必然更优；逐 seed 的符号分布才是可复现证据。

## 口径与限制（读表前先看）

- **不是显著性检验**：没有置信区间、没有 p 值、不做多重比较校正。这里只是把同一套确定性跑批在多个 seed 上重做一遍，报告效应符号分布。
- **seed 是人为选定的一组整数，不是随机抽样**：「N 个里 X 个为正」不能当概率估计，更不能外推到真实模型、其他任务集或其他故障注入率。
- **分辨率极粗**：10 条任务 × k=3，`pass^k` 只能取 0.10 的整数倍；`+0.10` 仅代表「一个任务从不是 k 次全过变成 k 次全过」，不是连续的效应量。
- **全部数字来自确定性模拟器**：`SeededBackend` 没有语言理解能力，注入的是人为噪声；这些数字**不构成任何真实模型能力、成本或延迟结论**，`tokens` / `latency_ms` 恒为 0。
- **护栏拒绝协议只在模拟器里验证过**：`[GUARD-REJECT]` 靠 `_pending_correct` 触发重发干净动作；真实模型能否读懂拒绝消息并改对，必须接 `OpenAIBackend` 后另开实验，本表不能外推。
- 效应只做 `|v| < 1e-9 → 0` 的浮点噪声归零，不做任何四舍五入或结果修饰。
